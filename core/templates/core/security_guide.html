Security Features

✓ Password Requirements
  • Minimum 8 characters
  • Not entirely numeric
  • Cannot contain username
  • Different from previous passwords
✓ Session Security
  • 24-hour session timeout
  • Automatic logout on browser close
  • Secure session cookies (HttpOnly)
  • CSRF protection enabled
✓ Password Reset
  • Email-based verification
  • Time-limited reset links (1 hour)
  • Role-specific portals
  • Multi-factor verification available
✓ Account Management
  • View account information
  • Login history tracking
  • Role-based access control
  • Admin account management
Pro Tips for Security
  • Use strong, unique passwords combining letters, numbers, and symbols
  • Change your password regularly (at least every 90 days)
  • Never share your login credentials with anyone
  • Always logout when using shared computers
  • Enable two-factor authentication if available
